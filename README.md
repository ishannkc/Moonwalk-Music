# 🕺 MoonWalk Music

**MoonWalk Music** is a lightweight, full-stack tribute to the artistry of Michael Jackson. This application serves as a digital gallery for his six most influential albums, utilizing a robust backend and a modern, minimalist frontend to deliver a seamless browsing experience.

🎵 Featured Albums
Off the Wall (1979)

Thriller (1982)

Bad (1987)

Dangerous (1991)

HIStory: Past, Present and Future, Book I (1995)

Invincible (2001)
